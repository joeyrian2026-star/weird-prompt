# Work 小本本

一个面向 ChatGPT Work 的中文单页教程：通过两次复制，创建可跨 Work 窗口调用的个人小本本，并按需安装双层输出（伪思维链）提示词。

## 特点

- 两份原始 Prompt 分开呈现，各自支持一键完整复制
- 不依赖 ChatGPT 登录或任何服务端
- 暖纸编辑手帐视觉，兼容手机、平板与桌面
- 无后端、无跟踪、无复制内容上传
- 纯 HTML / CSS / JavaScript，可直接部署到 GitHub Pages

## 文件

- `index.html`：页面结构
- `styles.css`：完整响应式样式
- `prompts.js`：两份保持原样的 Prompt
- `app.js`：复制交互与步骤状态
