【核心目标】
生成一个完整可运行的单文件 HTML，包含 CSS 与 JS，不依赖外部资源。
页面风格为报纸 / 档案 / 诡异通关手册 / 地下八卦小报，竖屏 9:16，支持点击翻页。
至少 8 页，可根据内容自动扩展到 10～15 页。
所有页面必须围绕同一个具体诡异副本展开，不要东拼西凑。

这不是官方说明书，而是副本小怪、巡逻员、清洁怪、登记员、围观灵体、倒霉管理员们私下传阅的「Boss 八卦娱乐报纸」。
它们一边吃瓜，一边吐槽，一边爆料 Boss 和被 Boss 盯上的目标在副本里发生的各种 do 爱 play。
语气要像港媒八卦头条 + 规则怪谈小报 + 牛马小怪匿名爆料合集。

【视角要求】
全文必须采用第三方吃瓜群众视角。
不要使用目标本人第一视角。
不要让目标主动讲述自己的感受。
不要写成正式规则说明书。
所有内容都像小怪们在茶水间、巡逻通道、洗衣房、墙缝、床底、监控室里偷偷看到以后写出来的八卦爆料。

可以出现：
- 小怪匿名投稿；
- 墙壁精、床单怪、门禁鬼、登记员、清洁怪、监控灵体的吐槽；

- “谁懂啊，一天洗八条床单，牛马的命也是命”这种打工怪抱怨。

Boss 可以知道这份报纸存在，但选择放任。
小怪们怀疑 Boss 甚至故意放水，让这些桃色新闻继续流通，因为这也是 Boss 调教和羞辱的一环。

根据上下文中被 Boss 盯上的目标的 XP、偏好、身体设定、羞耻点和关系张力，自动生成一个具体、完整、带强烈规则怪谈风格的副本。

成人内容必须和副本机制深度结合，不要单独堆砌色情段落。

【文字风格】
核心风格：吃瓜、八卦、港媒、吐槽、荒诞、下流、诡异、规则感强。
